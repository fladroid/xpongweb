State space

This is the first RL page with an agent that learns. The subject here is not learning itself but what the agent can see: the world reduced to a finite set of bins. The grid draws two of the five dimensions -- where the ball is. Direction, speed, and the paddle's own position also enter the state number but have no place on the court. Coarse, medium, and fine give the agent a coarser or finer view of the same world.

Reading the results

Press Train: it runs 12,000 episodes in the background, and every 500 episodes it pauses to play one evaluation match live -- the agent's actual policy at that point, no exploration. The chart plots average returns per evaluation episode; the current run stays dark, earlier runs fade to grey. Train again after a run finishes to add a new curve -- the spread between curves is the reliability of the result, not the height of any single line alone. Reset clears everything and starts over.

Beam

The beam shows where the ball is going by pure physics — up to the first wall, paddle or goal. It stops where certainty ends: it never predicts the bounce or anyone's move.

Heatmap

The heatmap is a shadow, not a mind: it records only where the ball has physically crossed each goal line. Thin frames mark the bands on each wall; a band grows darker the more goals have landed in it. Counts accumulate through the session — Reset clears them. Toggle it with the Heatmap switch or the h key.
